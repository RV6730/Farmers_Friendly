# Farmers Friendly

A smart farming assistant powered by AI, built for rural connectivity constraints.

## 🚀 Live Demo

- **Vercel:** [https://farmers-friendly.vercel.app](https://farmers-friendly.vercel.app)
- **AI Studio:** [https://ai.studio/apps/4f3b3a64-cb37-47f8-b5cb-9772eef6f02e](https://ai.studio/apps/4f3b3a64-cb37-47f8-b5cb-9772eef6f02e)

## ✨ Interactive Features

- **AI-Powered Diagnostics**: Analyze crop health and soil nutrients using camera integration.
- **Offline Mode & Sync**: Designed for rural constraints with an offline sync queue for pending data.
- **P2P Mesh Network**: Simulation of neighbor-to-neighbor connectivity via Bluetooth/WiFi.
- **Expert Access**: A directory and chat system to connect with agricultural specialists.
- **Field Tools**: Includes fertilizer calculators, GIS mapping, and USSD support.
- **Developer Simulator**: A built-in panel to simulate network (Offline/Online), mesh connectivity, and battery modes.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
