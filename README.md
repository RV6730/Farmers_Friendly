## ✨ Interactive Features

| Feature | Description |
|---|---|
| 🤖 **AI-Powered Diagnostics** | Analyze crop health and soil nutrients using camera integration powered by Gemini AI. |
| 📶 **Offline Mode & Sync** | Designed for rural constraints with an offline sync queue — works without a stable internet connection. |
| 🔗 **P2P Mesh Network** | Simulation of neighbor-to-neighbor connectivity for sharing data across farms without centralized infrastructure. |
| 👨‍🌾 **Expert Access** | Directory of agricultural experts with built-in chat capabilities for real-time advice. |
| 🧪 **Resource Tools** | Fertilizer calculators, USSD integration, and GIS mapping to plan and manage farm resources. |
| 🛠️ **Environment Simulator** | Developer panel to test internet, mesh, and battery constraints and validate app behaviour in tough conditions. |

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
